# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на идее Keep a Changelog, но адаптирован под практическое ведение небольшого браузерного расширения.

## v4.5.1

### Changed

- **Qwen**: подменю Qwen AI доведено до паритета с ChatGPT и Grok — добавлены команды «Сделать саммари» и «Провести фактчекинг» для выделенного текста (`summarizeInQwen`, `factCheckInQwen`). Новые действия автоматически появляются в контекстном меню, popup и на странице настроек; при желании их можно отключить индивидуально. Компактные заголовки спец-действий вынесены в общий экспорт `getCompactSpecialActionTitle` в `services.js` вместо дублирования в `menus.js` и `options.js`.

### Fixed

- Расширение снова работает в Яндекс Браузере: исчезает ошибка «Service worker registration failed. Status code: 2» и восстанавливается контекстное меню. Причина — Яндекс Браузер не поддерживает ES-модульные service workers (`"background": { "type": "module" }`), из-за чего фоновый скрипт не регистрировался и не создавал пункты меню. Фоновый скрипт теперь собирается в единый классический `background.bundle.js` без `import`/`export` (пересборка: `npm run build:background`, включена в `npm run check`). Chrome и другие Chromium-браузеры работают с бандлом без изменений.
- **Kimi**: домен сервиса обновлён с `https://www.kimi.com/` на `https://www.kimi.ai/` — в `services.js` (urlPattern, newUrl), `manifest.json` (host_permissions) и пересобранном `background.bundle.js`.
- **Ernie** и **StepFun** полностью удалены из расширения (контекстное меню, popup, страница настроек, `host_permissions`, описание манифеста): сервисы больше не работают. Сохранённые настройки с их флагами автоматически отбрасываются нормализацией при загрузке. Список поддерживаемых сервисов сокращён с 12 до 10.

## v4.4.1

### Fixed

- **Grok**: добавлен `delayMs: 1500` — пауза после загрузки SPA перед вставкой, чтобы React-инпут успел смонтироваться и подключить обработчики.
- **Grok**: включён `usePasteFirst: true` — вставка в contenteditable через paste-событие (по аналогии с ChatGPT в v4.3), безопасный фолбэк к `execCommand`/`textContent`.
- **Grok**: добавлены опциональные флаги профиля `settleMs: 300` и `retryOnInsertFail: true` — после успешной вставки значение перепроверяется через 300 мс; если фреймворк (React) затёр текст, попытка повторяется, вместо немедленного завершения с «успехом».
- **`waitForTabComplete`**: добавлена проверка текущего статуса таба через `chrome.tabs.get` — если `status === "complete"` уже сработал до подключения слушателя, ожидание завершается сразу, не дожидаясь 15-секундного таймаута.
