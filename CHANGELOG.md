# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на идее Keep a Changelog, но адаптирован под практическое ведение небольшого браузерного расширения.

## Unreleased

### Added

- Добавлен технический план развития проекта в `TECHNICAL_SPEC.md`.
- Добавлена документация для разработки и релизов.
- Добавлен скрипт сборки ZIP-архива расширения.
- Добавлена автоматическая проверка проекта через GitHub Actions.
- Добавлен базовый модуль пользовательских команд `custom-commands.js`.
- Добавлена нормализация пользовательских команд в настройках.
- Добавлено подменю **«Мои команды»** для пользовательских команд.
- Добавлена поддержка prompt-шаблонов с переменными: `{selection}`, `{url}`, `{title}`, `{date}`, `{service}`, `{pageText}`, `{youtubeUrl}`.
- Добавлено выполнение пользовательских команд из контекстного меню.
- Добавлен интерфейс управления пользовательскими командами на странице настроек.
- Добавлено создание, редактирование, отключение и удаление пользовательских команд.
- Добавлен предпросмотр итогового prompt для пользовательской команды.
- Добавлена валидация пользовательских команд перед сохранением.
- Добавлен модуль `page-extractor.js` для извлечения видимого текста текущей страницы.
- Команды с контекстом **«Текст страницы»** теперь подставляют реальный текст страницы в `{pageText}`.
- Добавлена обработка ошибки, когда текст страницы не удалось извлечь.
- Добавлен экспорт настроек в JSON.
- Добавлен импорт настроек из JSON с нормализацией данных.
- Добавлена кнопка полного сброса настроек с немедленным сохранением.
- Добавлен модуль `profiles.js` с профилями команд: базовый, маркетинг, редактура, перевод, исследование, YouTube и Hermes Agent.
- Добавлена настройка активных профилей команд.
- Добавлена привязка пользовательской команды к одному или нескольким профилям.
- Контекстное меню **«Мои команды»** теперь фильтруется по активным профилям.
- Активные профили и профили команд включены в импорт/экспорт настроек.
- Добавлен модуль `diagnostics.js` для журнала последних ошибок.
- Добавлена запись ошибок отправки в `chrome.storage.local` без сохранения текста prompt.
- Добавлена панель **«Диагностика»** в настройках.
- Добавлен просмотр и очистка журнала диагностики.
- `insertion.js` теперь возвращает подробные данные о вставке: селектор, тег, метод вставки, время выполнения, длину текста и проверенные селекторы.
- Добавлен модуль `youtube-templates.js` с редактируемыми YouTube-шаблонами.
- YouTube-команды теперь строятся из настроек, а не только из жёстко прописанного кода.
- Добавлены пять YouTube-сценариев: статья, краткое резюме, список фактов, Telegram-пост и тезисы для исследования.
- Добавлен модуль `youtube-options.js` для редактирования YouTube-шаблонов на странице настроек.
- Для YouTube-шаблонов добавлены включение/отключение, выбор сервиса, редактирование названия, редактирование prompt и предпросмотр.
- YouTube-шаблоны поддерживают переменную `{youtubeUrl}`.
- YouTube-шаблоны включены в импорт и экспорт настроек.
- Добавлены тесты для диагностики, профилей, пользовательских команд, настроек, меню и YouTube-шаблонов.

## v3.5

### Added

- Добавлено отдельное подменю **«Страницы и ссылки в Qwen»** с командами саммари, фактчекинга, перевода и тезисов для текущей страницы и ссылок.
- В настройках добавлены переключатели для управления видимостью Qwen-команд: общий и по каждому пункту.
- Обновлены тесты меню и настроек.

## v3.3

### Added

- Добавлены два отдельных YouTube-пункта в Gemini: для подробной статьи по транскрипции и для краткого резюме основных фактов.
- Обновлены тесты YouTube-prompt'ов под оба сценария.

## v3.2

### Changed

- Заменён YouTube-prompt для Gemini: теперь он просит обработать транскрипцию видеоролика в полноценную литературную статью на русском языке вместо извлечения ключевой информации.
- Обновлены тесты YouTube-prompt'а под новый текст.

## v3.1

### Changed

- Расширен YouTube-prompt для Gemini: теперь он просит извлекать все факты, цифры, статистику, даты, имена, названия, причинно-следственные связи, практические рекомендации, примеры и оговорки.
- Обновлены тесты YouTube-prompt'а под новый подробный текст.
- Синхронизировано описание YouTube-сценария в документации с новым prompt'ом.

## v3.0

### Added

- Добавлен единый блок команд для страниц и ссылок со сценариями саммари, фактчекинга, перевода и тезисов.
- `page` и `link` сценарии объединены в одно подменю **«Страницы и ссылки»**.
- Логика промптов для страниц и ссылок вынесена в общий builder.
- Добавлен popup для быстрой отправки выделенного текста в AI-сервисы.
- Popup умеет запускать специальные команды и открывать настройки.

### Changed

- Нажатие на иконку расширения теперь открывает popup вместо страницы настроек.
