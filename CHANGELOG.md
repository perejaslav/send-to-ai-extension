# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на идее Keep a Changelog, но адаптирован под практическое ведение небольшого браузерного расширения.

## Unreleased

### Added

- Добавлен технический план развития проекта в `TECHNICAL_SPEC.md`.
- Добавлена документация для разработки и релизов.
- Добавлен скрипт сборки ZIP-архива расширения.
- Добавлена автоматическая проверка проекта через GitHub Actions.

## v3.5

### Added

- Добавлено отдельное подменю **«Страницы и ссылки в Qwen»** с командами саммари, фактчекинга, перевода и тезисов для текущей страницы и ссылок.
- В настройках добавлены переключатели для управления видимостью Qwen-команд: общий и по каждому пункту.
- Обновлены тесты меню и настроек.

## v3.3

### Added

- Добавлены два отдельных YouTube-пункта в Gemini: для подробной статьи по транскрипции и для краткого резюме основных фактов.
- Обновлены тесты YouTube-prompt'ов под оба сценария.

## v3.2

### Changed

- Заменён YouTube-prompt для Gemini: теперь он просит обработать транскрипцию видеоролика в полноценную литературную статью на русском языке вместо извлечения ключевой информации.
- Обновлены тесты YouTube-prompt'а под новый текст.

## v3.1

### Changed

- Расширен YouTube-prompt для Gemini: теперь он просит извлекать все факты, цифры, статистику, даты, имена, названия, причинно-следственные связи, практические рекомендации, примеры и оговорки.
- Обновлены тесты YouTube-prompt'а под новый подробный текст.
- Синхронизировано описание YouTube-сценария в документации с новым prompt'ом.

## v3.0

### Added

- Добавлен единый блок команд для страниц и ссылок со сценариями саммари, фактчекинга, перевода и тезисов.
- `page` и `link` сценарии объединены в одно подменю **«Страницы и ссылки»**.
- Логика промптов для страниц и ссылок вынесена в общий builder.
- Добавлен popup для быстрой отправки выделенного текста в AI-сервисы.
- Popup умеет запускать специальные команды и открывать настройки.

### Changed

- Нажатие на иконку расширения теперь открывает popup вместо страницы настроек.

## v2.8

### Added

- Добавлена специальная команда для выделенного текста: **«Провести фактчекинг в ChatGPT»**.
- В настройках добавлены отдельные переключатели для каждой специальной команды.

## v2.6

### Added

- Добавлена команда контекстного меню для текущей страницы: **«Сделать саммари текущей страницы в ChatGPT»**.
- Добавлен отдельный prompt-builder для саммари текущей страницы по URL.
- Обновлена документация под новый сценарий page-context меню.

## v2.5

### Added

- Добавлена команда контекстного меню для любой ссылки: **«Сделать саммари страницы в ChatGPT»**.
- Добавлен prompt-builder для подробного саммари страниц по URL.
- Обновлена документация под новый сценарий работы со ссылками.

## v2.4

### Added

- Добавлен badge-статус на иконке расширения для результатов вставки: `OK` / `ERR`.
- Специальные команды доступны в том же подменю **«Отправить в AI»** и их можно скрыть в настройках.

### Changed

- Сужены `host_permissions` до точных доменов поддерживаемых сервисов.
- Добавлен `aistudio.google.com`.
- `background.js` разделён на модули конфигурации, настроек, меню, YouTube-логики и вставки текста.
- Клик по иконке расширения стал открывать настройки.

## v2.3

### Added

- Добавлена страница настроек расширения.
- Можно менять порядок сервисов, включать и отключать их, выбирать сервис по умолчанию.
- Добавлен быстрый пункт контекстного меню **«Отправить в <сервис> (по умолчанию)»**.
- Обновлён комплект иконок расширения `16/48/128`.
- Добавлена явная настройка `action.default_icon` для тулбара.

## v2.2

### Added

- Добавлен **Google AI Studio** (`https://aistudio.google.com/app/prompts/new_chat`) в контекстное меню.
- Настроена вставка текста в поле промпта Google AI Studio.
- Обновлена версия расширения до `2.2`.
