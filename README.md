# Send to AI - Отправить в AI

Расширение для Chrome/Edge, которое добавляет команды в контекстное меню и позволяет быстро отправлять выделенный текст в популярные AI-сервисы.

## Возможности

- Отправка выделенного текста в AI из контекстного меню
- Повторное использование уже открытой вкладки AI (фокус + вставка)
- Автоматическая вставка текста в поле ввода
- Интеграция с YouTube-ссылками для Gemini с подробным prompt'ом на извлечение всей ценной информации
- Единый блок команд для страниц и ссылок: саммари, фактчекинг, перевод и тезисы
- Настраиваемый список сервисов (порядок, включение/выключение, сервис по умолчанию)
- Отдельная настройка специальных команд в контекстном меню
- Пользовательские команды с собственными prompt-шаблонами
- Профили пользовательских команд: базовый, маркетинг, редактура, перевод, исследование, YouTube и Hermes Agent
- Извлечение видимого текста текущей страницы для команд с переменной `{pageText}`
- Импорт и экспорт настроек в JSON
- Журнал диагностики последних ошибок без сохранения текста prompt
- Светлая и тёмная тема страницы настроек с переключателем
- Единая иконка расширения для тулбара и контекстного меню
- Статус вставки через badge на иконке расширения (`OK` / `ERR`)
- Быстрый popup для отправки выделенного текста и запуска спецкоманд

## Специальные команды

- **Отправить и перевести в Qwen** - перевод выделенного текста на русский перед отправкой
- **Отправить и перевести в ChatGPT** - перевод выделенного текста на русский перед отправкой
- **Сделать саммари в ChatGPT** - краткое саммари выделенного текста
- **Провести фактчекинг в ChatGPT** - проверка утверждений в выделенном тексте с классификацией достоверности
- **Статья по YouTube-транскрипции в Gemini** - открыть YouTube-ссылку в Gemini с prompt'ом для обработки транскрипции видеоролика в полноценную литературную статью на русском языке
- **Краткое резюме YouTube-видео в Gemini** - открыть YouTube-ссылку в Gemini с prompt'ом для краткого резюме всех основных фактов из видео
- **Страницы и ссылки** - единый submenu для саммари, фактчекинга, перевода и тезисов по странице или ссылке в ChatGPT
- **Страницы и ссылки в Qwen** - аналогичный submenu с отправкой команд в Qwen
- **Мои команды** - пользовательские prompt-команды из настроек
- **Отправить в <сервис> (по умолчанию)** - быстрый пункт для выбранного в настройках сервиса

## Установка

1. Скачай или клонируй репозиторий
2. Открой страницу расширений в браузере
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
3. Включи **Режим разработчика**
4. Нажми **Загрузить распакованное расширение**
5. Выбери папку проекта

## Как пользоваться

### Базовый сценарий

1. Выдели текст на веб-странице
2. Нажми правой кнопкой мыши
3. Выбери **"Отправить в AI"**
4. Выбери нужный AI-сервис
5. Текст автоматически вставится в поле ввода сервиса

### YouTube-сценарий

1. Нажми правой кнопкой мыши по ссылке на YouTube (`youtube.com` или `youtu.be`)
2. Выбери **«Статья по YouTube-транскрипции в Gemini»** или **«Краткое резюме YouTube-видео в Gemini»**
3. В Gemini откроется нормализованная ссылка и prompt для выбранного сценария: либо подробная литературная статья по транскрипции, либо краткое резюме всех основных фактов из видео

### Сценарий для любой ссылки

1. Нажми правой кнопкой мыши по любой ссылке на странице
2. Выбери **"Сделать саммари страницы в ChatGPT"**
3. В ChatGPT откроется ссылка и подробный запрос на саммари страницы

### Сценарий для текущей страницы

1. Нажми правой кнопкой мыши по пустому месту на открытой странице
2. Выбери **"Сделать саммари текущей страницы в ChatGPT"**
3. В ChatGPT откроется URL текущей страницы и подробный запрос на саммари

### Пользовательские команды

1. Открой настройки расширения
2. В блоке **«Мои команды»** нажми **«Добавить команду»**
3. Укажи название, сервис, контекст и prompt-шаблон
4. При необходимости привяжи команду к одному или нескольким профилям
5. Используй переменные: `{selection}`, `{url}`, `{title}`, `{date}`, `{service}`, `{pageText}`, `{youtubeUrl}`
6. Нажми **Сохранить**
7. Открой контекстное меню на странице и выбери команду в подменю **«Мои команды»**

Для команд с контекстом **«Текст страницы»** расширение извлекает видимый текст текущей страницы и подставляет его в `{pageText}`.

### Профили команд

1. Открой настройки расширения
2. В блоке **«Профили команд»** выбери активные профили
3. В форме пользовательской команды отметь, к каким профилям она относится
4. Нажми **Сохранить**

Если выбран режим **«Все профили»**, в меню показываются все включённые пользовательские команды. Если выбран конкретный профиль, например **«Маркетинг»**, расширение показывает команды этого профиля и команды без профиля. Команды без профиля считаются универсальными.

### Тема настроек

1. Открой настройки расширения
2. Во вкладке **«Основное»** найди блок **«Оформление настроек»**
3. Нажми **«Включить тёмную тему»** или **«Включить светлую тему»**

Выбор темы сохраняется сразу и применяется при следующем открытии настроек.

### Диагностика

1. Открой настройки расширения
2. Перейди к блоку **«Диагностика»**
3. Посмотри последние ошибки отправки
4. При необходимости нажми **«Обновить»** или **«Очистить журнал»**

Журнал диагностики хранит статус ошибки, сервис, команду, URL, селектор поля ввода, метод вставки и технические числа. Текст prompt не сохраняется.

### Перенос настроек

1. Открой настройки расширения
2. В блоке **«Импорт и экспорт»** нажми **«Экспорт настроек»**
3. Сохрани JSON-файл
4. На другом компьютере установи расширение и открой настройки
5. Нажми **«Импорт настроек»**
6. Выбери сохранённый JSON-файл
7. Подтверди замену текущих настроек

Импорт проходит через нормализацию: если в файле есть устаревшие или лишние данные, расширение постарается безопасно привести их к актуальному формату.

### Настройка меню

1. Открой настройки расширения на странице расширений браузера
2. Измени порядок сервисов в контекстном меню перетаскиванием
3. Отключи ненужные сервисы чекбоксами
4. Выбери сервис по умолчанию для быстрого пункта
5. Управляй специальными командами по отдельности
6. Создай или измени пользовательские команды
7. Настрой профили команд
8. Нажми **Сохранить**

### Иконка расширения

- Нажатие на иконку в тулбаре открывает страницу настроек
- После отправки текста иконка кратко показывает `OK`, если вставка прошла успешно, и `ERR`, если сервис открылся, но поле не нашлось или вставка не удалась

## Технические детали

- **Manifest V3**
- **Конфиг-ориентированная маршрутизация** сервисов и команд
- **Детерминированный выбор вкладки** (берется последняя активная из совпавших)
- **Унифицированная вставка текста** с fallback-стратегиями для разных редакторов
- **Строгая валидация YouTube-хостов** и очистка URL
- **Пользовательские prompt-шаблоны** с переменными контекста
- **Профили команд** с фильтрацией пользовательских команд в меню
- **Извлечение видимого текста страницы** с ограничением длины
- **Экспорт и импорт настроек** через JSON с версией схемы
- **Диагностика ошибок** через `chrome.storage.local` без сохранения prompt
- **Тема страницы настроек** через `chrome.storage.local` и атрибут `data-options-theme`

### Разрешения

- `contextMenus` - создание пунктов контекстного меню
- `tabs` - поиск, активация и фокус вкладок
- `scripting` - инъекция скриптов вставки и извлечения текста страницы
- `activeTab` - быстрый доступ к выделению в текущей вкладке из popup
- Точные host permissions только для поддерживаемых доменов AI-сервисов
