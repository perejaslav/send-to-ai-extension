## v4.6.1 — хранилище

- В v4.6 шаблоны весили ~40 КБ, а `chrome.storage.sync` держит 8 КБ на элемент.
  Сохранение шаблонов падало с `kQuotaBytesPerItem quota exceeded`.
- Фикс (#11): модуль `settings-storage.js`.
  - `youtubeTemplates` и `customCommands` лежат в `storage.local`, остальное — в `sync`.
  - При чтении — однократный перенос этих ключей из `sync` в `local`.
  - Все точки чтения и записи (`background.js`, `options.js`, `popup.js`, `youtube-options.js`) идут через модуль.
  - Фон слушает изменения в обеих областях.
- Побочный эффект: пользовательские команды больше не синхронизируются между устройствами.

## Что важно знать

- Сохранённые пользователем шаблоны перекрывают встроенные (`normalizeYouTubeTemplates`).
  Старые шаблоны из `sync` переносятся в `local` как есть.
  Новые тексты появятся после кнопки «Вернуть шаблон по умолчанию» у нужного шаблона
  (после её выпуска), «Сбросить все настройки» (сбрасывает всё) или ручной замены.
- `background.bundle.js` генерируется: `npm run build:background` (входит в `npm run check`).
- Версии: `manifest.json` и `package.json` должны совпадать.
- `buildYouTubePrompt` в `youtube.js` и `YOUTUBE_MENU_TITLES` в `services.js` нигде не используются.
- Ветка `archive/floating-ai-overlay-v4.7.1-tested` — отдельная ветка с плавающим окном (overlay), в `main` не влита.
  В ней есть свой фикс хранилища; при её слиянии будет конфликт с `settings-storage.js` из `main`.
