## Что важно знать

- Сохранённые пользователем шаблоны перекрывают встроенные (`normalizeYouTubeTemplates`).
  Новые тексты появятся только после «Сбросить все настройки» (сбрасывает всё) или ручной замены.
- `background.bundle.js` генерируется: `npm run build:background` (входит в `npm run check`).
- `buildYouTubePrompt` в `youtube.js` — старый промпт, нигде не вызывается (только в тесте).
- `YOUTUBE_MENU_TITLES` в `services.js` нигде не используется.
